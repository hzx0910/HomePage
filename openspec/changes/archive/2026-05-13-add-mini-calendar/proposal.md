## Why

首页目前有搜索、书签和待办三个模块，缺少日期感知能力。添加一个极简月历组件放在待办区域上方，让用户在管理待办的同时能快速查看日期，提升首页的实用性。

## What Changes

- 在待办卡片上方新增一个等宽的极简月历组件
- 月历横轴为周一到周日，显示当月所有日期
- 高亮标记今天的日期
- 顶部显示当前年月，支持左右箭头切换上一个月/下一个月
- 月历与待办卡片等宽，视觉风格与现有深色主题一致

## Capabilities

### New Capabilities
- `mini-calendar`: 极简月历组件，显示月度日历网格，标记今天，支持月份前后切换

### Modified Capabilities

## Impact

- `index.html`：在 `#todos-card` 上方新增月历 HTML 结构，新增对应 CSS 样式，新增 Calendar JS 模块
- 月历与待办共享右侧 1fr 列，需要调整布局使月历和待办垂直排列在同一列中
- 无外部依赖，纯 CSS/JS 实现
